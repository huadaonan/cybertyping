# 新手入门与周边键训练

入口：`#/intro`。完成坐姿准备、双手归位、基准键练习和小练习后，
自动进入第五项「基准键周边」，随后是第六项「基准键周边键」。
已经练过旧版五节课程的玩家保留原有入口权限和课程记录。

「基准键周边」包含最初设计的 10 节短课，左右手分别学习，每次只练一根手指。
「基准键周边键」保留 5 节左右手合练，依次为食指基础、中指、无名指、
小指及食指进一步拓展。两套课程共用「认识新键」「跟着练」和「自己试试」。
跟练有 16 个目标，自测有 24 个目标。自测只统计每个目标第一次是否按对。
按错不推进，连续错两次显示位置提示。完成即可继续，首次按对率达到
90% 时标记为已掌握，否则建议复习。重练不会取消已经获得的掌握状态。

10 节课的记录按玩家保存在 `cybertype-intro-surrounding-single:<playerId>`，
5 节课继续使用 `cybertype-intro-surrounding-v2:<playerId>`，两者互相独立。
入门进度仍使用 `cybertype-intro:<playerId>`，版本 2 会兼容旧的五节课入口。
新玩家完成 10 节后解锁左右手合练。不包含云端同步。
刷新或重新进入会保留已完成课程，并重启当前未完成的短步骤。
切换窗口、隐藏页面或按 Escape 会暂停，两个「继续练习」按钮均可恢复。
两套周边键课程的三个步骤底部均提供「上一步」：第一步返回课程列表，
第二、三步分别回到前一步的开头；已完成课程的成绩和掌握标记保留。
第一步为第二步的练习序列预留相同空间，说明区保持稳定高度，同一节课内
前两步切换不滚动到页首，保持键盘和手形的显示位置稳定。
练习页收紧标题、步骤及说明区的间距，周边键课程与基准键练习使用相同的
键盘宽度、键帽尺寸及桌面 400px 展示区，保持完整手形和手指对位。
底部操作区吸附在可见区域；自测展开提示时恢复正常排版，避免遮挡键盘。
窄屏底部省略重复说明，保留全部操作按钮。
「自己试试」每个目标首次输入正确时，屏幕中央显示「正确，太帅了！」和
林克高举大师之剑的动画；首次错误显示「不太对，再试试！」和林克加油动画。
林克和文案直接放在自测区中央的预留位置，没有弹窗背景、边框和遮罩，不覆盖
目标按键、键盘或按钮。预留空间保持固定，出现或消失时页面不跳动。
进入自测后林克默认可见，素材在进入课程时提前加载。提示文案和动作持续约
1.6 秒，然后保留林克姿势，可持续输入；纠错、重复按住、输入法及快捷键不重复触发。
返回、暂停或离开页面会清除动画，系统设置减少动态效果时使用静态姿势。
林克素材 `link-poses.png` 保存在本地，通过 CSS 分别展示并播放举剑及加油效果。

练习界面沿用线上入门页的左右布局、键盘比例和手形素材：教学步骤在左，
键盘和手形叠放在右。说明区和顶部留白已缩小，窄屏会自动改为上下布局。
手形素材保存在本目录，练习时不需要从线上站点加载。
入门页两份样式表由根目录 `index.html` 的 `<head>` 一次性加载；练习更新画面时
不再删除、重建样式链接，避免公网下重新应用样式造成文字和布局闪动。
桌面端页面使用可用宽度，键盘区最大宽度为 1000px，手形区高度为 400px，
键帽高度为 52px，与线上入门页保持相同尺寸，不再使用压缩后的桌面比例。
双手分别以 A/S/D/F、J/K/L/分号四个键的实际中心校准，窗口变化后自动重新对齐。
底部「继续练习／暂停练习」右侧的「显示手形」开关控制手形显示，键盘与练习
进度不变。设置按当前玩家保存，基础练习与两套周边键课程共用。
「自己试试」隐藏键盘时，先点「提示」即可显示键盘及手形开关。

本项目提供静态网页文件，没有 Ruby、Homebrew 或构建依赖。
修改 `IntroView-v2.js`、`SurroundingCourse.js`、`surrounding.js`、`visuals.js`
及相关 CSS 后，刷新页面即可验证。

运行逻辑测试：

```sh
node --test assets/intro/*.test.mjs
```

浏览器验收应覆盖：旧版小练习自动衔接、三步完成、错误纠正与成绩、两处暂停
恢复按钮、刷新恢复、返回课程、标点键、三键食指课程、切换玩家及窄屏布局。
